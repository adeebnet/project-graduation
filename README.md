# Bot Discord Dukungan Teknis

## Hai!, Selamat Datang di Bot Discord Dukungan Teknis🤖🔧
Kami menyediakan bot discord ini untuk membantu pengguna/pembeli di toko kami, Semua Bisa Kamu Beli!
mengenai pembelian sampai pesanan kamu yang bisa kamu tanyakan disini!

## Terdapat 2 fitur bantuan teknis utama pada bot kami⚙

1. **command !help**
Menampilkan beberapa pilihan pertanyaan dari bot dalam bentuk tombol.
Pengguna cukup menekan kategori yang tersedia dan bot akan langsung memberikan jawaban.

🔑Topik yang tersedia adalah:

- 🛒Cara melakukan pembelian
- 📦Cek status pesanan
- ❌Pembatalan pesanan
- ⚠️Barang rusak
- 🎧Hubungi dukungan teknis
- 🚚Perubahan metode pengiriman

*Dirancang supaya pengguna cepat menemukan solusi tanpa perlu menunggu jawaban admin kami.*

2. **command /custom**
Untuk menggunakan command ini sebaiknya buat tiket anda terlebih dahulu, supaya admin dapat membaca
pertanyaan yang kamu ingin tanyakan selain 6 tombol tersebut

- 🎟Bagaimana cara membuat tiket?
Cari bagian channel "ticket" di paling bawah
kemudian buat tiket
dan pengguna akan di masukkan ke channel privat yang hanya dapat di akses pengguna dan admin kami

- Bagaimana cara menggunakan command /custom?
Masuk ke channel tiket milik anda
kemudian ketik command /custom [pertanyaan] <--- isi pertanyaan anda
dan akan langsung di kirimkan ke admin kami.

*Kekurangannya adalah, pengguna harus menunggu terlebih dahulu jawaban dari admin, kami merekomendasikan untuk menggunakan command !help*
